# Image Classification Using CNN

A convolutional neural network (CNN) project for classifying images from the CIFAR-10 dataset into 10 classes:

`airplane`, `automobile`, `bird`, `cat`, `deer`, `dog`, `frog`, `horse`, `ship`, `truck`.

This project was prepared for the **Summer Training Programme on Data Science, Machine Learning & Agentic AI**, organised by **Electronics & ICT Academy, IIT Roorkee**.

## Project objective

The objective is to build, train, and evaluate a CNN that learns visual features directly from images and predicts the correct CIFAR-10 class.

## What the project includes

- CIFAR-10 loading and preprocessing
- Train/validation/test split
- Image visualization
- Data augmentation
- CNN model construction
- Model training with early stopping and learning-rate reduction
- Accuracy and loss curves
- Test-set evaluation
- Classification report
- Confusion matrix
- Sample predictions
- Saved trained model

## Dataset

CIFAR-10 contains 60,000 RGB images of size 32×32 pixels in 10 balanced classes.

- Training images: 50,000
- Test images: 10,000
- Classes: 10

The notebook reserves 10% of the original training data for validation.

## Model

The network uses:

1. Data augmentation
2. Convolutional layers for feature extraction
3. Batch normalization for stable training
4. Max pooling for spatial downsampling
5. Dropout for regularization
6. Dense layers for classification
7. Softmax output over 10 classes

The model is trained using the Adam optimizer and sparse categorical cross-entropy loss.

## Run in Google Colab
